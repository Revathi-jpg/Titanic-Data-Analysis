
# Titanic Dataset Analysis Using Python

## 📌 Project Overview
This mini project focuses on basic Data Analysis using the Titanic Dataset.
It demonstrates how Python libraries are used to load, explore,
understand and clean datasets.

## 🎯 Objectives
- Understand the structure of a dataset.
- Explore rows and columns.
- Identify missing values.
- Perform basic data cleaning.
- Learn Python libraries used in Data Analysis.

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Jupyter Notebook

## 📚 Concepts Covered

### 1. NumPy
- Creating arrays
- Numerical operations
- Mean, maximum and minimum

### 2. Pandas
- Reading CSV files
- Creating and working with DataFrames
- Dataset exploration
- Data inspection

### 3. Dataset Exploration
- head()
- tail()
- shape
- columns
- info()
- describe()
- dtypes

### 4. Data Cleaning
- Identifying missing values using isnull().sum()
- Handling missing values using fillna() and dropna()
- Removing unwanted columns using drop()
- Identifying duplicates using duplicated()
- Removing duplicates using drop_duplicates()

### 5. Matplotlib
- Basic data visualization
- Line charts
- Bar charts
- Histograms
- Pie charts

## 📊 Dataset Information
- Dataset Name: Titanic Dataset
- Total Rows: 891
- Total Columns: 12
